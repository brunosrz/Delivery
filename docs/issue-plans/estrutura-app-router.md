## Objetivo
Organizar o App Router para manter páginas, layouts, actions e APIs previsíveis.

## Escopo
Definir convenções de pastas, carregamento, erros, loading states, cache e limites server/client; registrar uma estratégia de mudança sem downtime.

## Testes e aceite
Validar todas as rotas, fallback de erro, estados vazios, permissões e build em ambiente limpo.
